# seandobbins.com

Website for jazz drummer and educator Sean Dobbins, home of The Barbershop. Astro 7 on Vercel, Decap CMS for content, MailerLite for the resource library's email gate.

- `CLAUDE.md` — stack, brand rules, constraints, and the "Sean edits only via the CMS" principle.
- `HANDOVER.md` — Sean's guide to the editor, plus Dana's setup notes (Vercel, OAuth, MailerLite, Resend, Auralis).
- `.env.example` — every environment variable the site uses.

```
npm install
npm run dev
npm run build
```
